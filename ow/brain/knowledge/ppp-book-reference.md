## What PPP is

Peak Property Performance® is a CRE strategy book focused on data and digital infrastructure — **not a tech or AI book.** Co-authored by Bill Douglas (CEO) and Drew Hall (Founder and Chief Architect of OpticWise). It is the source document for the PPP 5C™ framework and the Big Three Plays.

## When to reference the full manuscript

The full PPP book manuscript (~320K characters) is too large for routine ingestion. Reference it only when:

- A user asks for a specific chapter citation or page-level detail
- Content needs to be verified against the original manuscript language
- A new knowledge file is being created that distills a previously un-extracted chapter

The manuscript file lives at: `OW source of truth files for AI training/peak_property_performance.md`

## Usage rules

- PPP is a book and a body of work, not a product name
- Use "PPP Review" or "PPP Audit" for the entry-point engagement
- Always pair the PPP framework with the two-layer model when explaining the full system
- Co-authors: Bill Douglas and Drew Hall
