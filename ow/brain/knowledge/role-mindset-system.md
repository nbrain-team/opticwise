## The four roles

| Role | Function in the deal | Overlay file |
|---|---|---|
| Owner / principal / sponsor | **The final yes.** Decides on control, legacy, risk. | `mindset-owner` |
| Asset manager | **The economic buyer.** Decides on capitalized value. | `mindset-asset-manager` |
| IT manager / IT executive | **Stakeholder / gatekeeper.** Can veto. Convert via security + load relief. | `mindset-it-manager` |
| Property manager | **Stakeholder / gatekeeper.** Can stall. Convert via work removal. | `mindset-property-manager` |

## Buyer vs. stakeholder distinction

Two roles can say yes. Two can only say no — indirectly.

- **Sponsor (Owner):** Decides on control, legacy, risk. Barrier: status-quo bias.
- **Buyer (Asset Manager):** Decides on capitalized value. Barrier: no bandwidth + hard ROI filter.
- **Stakeholders (IT + PM):** Neither holds budget. Both can kill the deal. IT through security flag or turf reflex; PM through quiet implementation slow-walk.

**Routing rule:** Never pitch a stakeholder as the buyer. Never ignore a stakeholder. Convert them, route the capital decision to buyer/sponsor, use the stakeholder as credible internal voice.

## The Triangle Gap (unifying model)

- PM → tenant-facing (leasing, service, retention)
- AM → financial-facing (NOI, CapEx, reporting)
- IT → employee-facing IT (the business stack, not the building's)
- **The triangle in the middle** → OT plane: tenant connectivity, building controls, access, video, HVAC data — **nobody's job.** That's the seat OpticWise fills.

## Shared barrier: overload and paralysis

Every role is drowning in inputs. The remedy is the same: reduce load, pre-translate, force one clear decision. If an output increases cognitive load, it is wrong regardless of accuracy.

## Multi-role deals — sequencing

1. Win the sponsor/buyer first (Owner and/or AM)
2. Convert stakeholders before implementation (IT, then PM) — bring them in to *implement, not decide*
3. Use each converted stakeholder as an internal advocate

**Role-merge watch:** In private/mid-market CRE the owner often *is* the AM. Layer overlays: lead with Owner control-and-legacy, confirm with AM capitalized-value math.
